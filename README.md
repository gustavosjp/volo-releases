# Volo — downloads

Instaladores do **Volo**, o rastreador de voos para Microsoft Flight Simulator 2020/2024.

Baixe a versão mais recente em **[Releases](../../releases/latest)** (`Volo-Setup-x.y.z.exe`).
Depois de instalado, o Volo se atualiza sozinho a partir deste repositório.

Este repositório contém apenas os instaladores publicados — o código-fonte é privado.
